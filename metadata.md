id: Metadata
============

**Name nomenclature**: Code(child)(grandchild).md

- **None:**          Information
- **Date (Notes):**  YYMMDD
- **Date (Weekly):** WWwYY
- **Code:**          AA00
- **Child:**         a
- **GrandChild:**    00


### Examples

03w25.md    -> Daily notes from week 3: 13 to 19 January 2025 -> Without type for faster creation and access.   
AA01.md     -> Information note, theme AA, first note.   
AA01a.md    -> Information note (child) from 30 January 2025, theme AA, child sub-theme a.   


Files
-----

YYYYMMDD-project-id-[action]-[v0000].ext

- **action:** test, run, video, etc.



Meeting notes
-------------

YYMMDD-id-meet.md


Code Metadata
-------------

00:             Metadata files    
aa(Lowercase):  Child note    
P:              Project
